# APICraft

# File Structure
| File              | Responsibility                                   |
| ----------------- | ------------------------------------------------ |
| `database.py`     | Creates the database engine (connection)         |
| `models.py`       | Database structure                               |
| `dependencies.py` | Creates and provides a database session          |
| `schemas/user.py` | Validates request and response data              |
| `main.py`         | Starts the application and initializes resources |
| `user.py`         | API data validation                              |
| `users.py`        | API endpoints                                    |
| `user_service.py` | Database/business operations                     |
